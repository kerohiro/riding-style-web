# RIDE ATLAS

iPhoneのSafariでGPS・IMUを記録し、バイクの走行経路・加速度・推定リーン角を振り返る静的Webアプリ。

## 公開サイト

https://kerohiro.github.io/riding-style-web/

iPhoneでSafariから開きます。アプリのインストールやXcodeの署名は不要です。「共有 → ホーム画面に追加」でも利用できます（オフライン動作は非対応）。

## 機能

- 速度・合成加速度・推定リーン角の軌跡カラー
- 地図の傾斜表示、水平加速度の矢印、リーン角を表す模式的な3D柱
- タイムラインと地図クリックによるサンプル選択・再生
- 回転できるThree.jsの車体姿勢・3D加速度ベクトル
- GPSとDeviceMotionの取得、直立基準設定、最大10Hzのサンプル記録
- IndexedDBへの保存、約5秒ごとのチェックポイント、走行ライブラリ
- JSON入出力、ネイティブSwift版の既存JSON（2001年基準の日時）読込
- キー不要のOpenStreetMap（MapLibre）と、APIキーを使うGoogle Maps切替
- Apple Mapで選択位置を開くリンク

## 記録前のセンサー動作確認

「センサーを許可」を押すと、3D TELEMETRYが「センサー確認」へ切り替わり、実際のIMU受信に合わせて車体の左右・前後の傾きと加速度矢印が動きます。GPS許可・記録開始は不要で、プレビューだけでは走行データは作成・保存しません。「走行データ」ボタンやタイムライン操作でデモ・保存済み走行の表示に戻れます。

基準設定前は端末縦向きの軸を使い「未校正」と表示します。固定後に直立基準を設定すると基準姿勢からの変化になります。センサー未対応・拒否・未受信・2秒以上の受信停止を表示します。モデルをドラッグしたときの視点変更と、センサーによる車体姿勢の変化は別です。実機のSafariでセンサーを許可し、画面を表示したまま確認してください。

## 再生速度と記録の一時中断

- RIDE TIMELINEの「再生倍率」へ0.01〜100の任意の倍率（例：0.5、1.25、2、8）を入力できます。1倍はログの実時間に対応します。再生中の変更も現在位置から連続して反映します。タブを非表示にすると再生を一時停止します。
- 再生は記録時刻に沿うrequestAnimationFrame駆動です。重複したGPS座標を測位区間としてまとめ、区間全体で位置・方位を補間します。IMU姿勢と加速度も再生時刻で補間します。地図の静的な経路やグラフ全体を毎フレーム作り直さず、位置・姿勢・カーソルを更新します。10秒を超える測位欠落や2kmを超える位置飛びは補間しません。
- 記録中の「記録を一時中断」でGPS取得と走行サンプルの保存を止め、そこまでのデータを端末へ保存します。「記録を再開」で同じ走行IDへ追記します。「終了して保存」は走行を完了する操作です。
- 中断中に画面をロック・別アプリへ移動しても、ページのセッションが生きていれば戻って再開できます。ブラウザ強制終了・再読込後の同一ログへの記録再開は未対応です。そこまでの保存ログはライブラリから開けます。再開時は有効なIMUと新しいGPS測位を待ちます。端末を取り外した場合は、停車・直立状態で基準を設定し直してください（中断中も基準設定可）。
- サンプルの`segment`とログの`pauses`に中断区間を保存します。中断前後を地図の軌跡で接続せず、再生では中断時間を除外します。既存のJSONもそのまま読み込めます。

## 計測

1. 停車し、iPhoneを車体に縦向き・画面をライダー側・背面を前方に固定。
2. 「① センサーを許可」。位置情報も記録開始時に許可。
3. 車体を直立させ「② 直立基準を設定」。以後は固定方向を変更しない。
4. 「記録開始」。画面を表示したまま使用。
5. 停車して「終了して保存」。必要に応じJSONを書き出す。

計測中の画面非表示・別アプリ・ロック時は停止して保存を試みます。一時中断中はページが保持されている間はその状態を維持します。強制終了時の完全な保存は保証できません。ブラウザのデータ削除で走行データも消えるので、JSONでバックアップしてください。

## 表示設定・現在地追従

- マーカーと追従カメラは同じ表示位置を使います。記録中は約600msの位置補間、ログ再生中は記録時刻に沿う毎フレーム補間を使います。表示のみの補間で、保存データを加工したり未来位置を推測したりしません。大きく離れた位置への移動（2km超）や初回測位は即時表示します。
- 地図上の「地図の向き」で「北を上」「進行方向を上」を選択できます。向きの設定はブラウザへ保存します。GPS進行方向を使用し、欠測時は3m以上の移動から方位を推定します。低速時（1.5m/s未満）・方位不明時は直前の向きを保持します。方位は最短角度で補間します。Google Mapsではベクター描画を要求しますが、端末・API側が非対応の場合は回転に制約があります。Google Mapsでの実機確認は未実施です。

- 計測開始時に「現在地追従 ON」へ切り替わり、有効なGPS更新ごとに現在位置を地図の中心にします。ズーム・向きは維持します（最初の測位はズーム15）。ボタンでOFFにでき、全体表示を押すと追従を解除し、選択位置移動で追従を再開します。標準地図・Google Maps双方に対応します。
- ログの再生開始時も追従がONになり、選択サンプルの位置に地図が同期します。追従ONではタイムライン・軌跡クリックにも連動します。記録中は「現在地追従」、ログ表示時は「再生位置追従」と表示し、ズームや向きを維持します。
- RIDE TIMELINEの縦軸は推定リーン角（度）で、正は右、負は左。目盛は最低±60°、それ以上のデータがあれば拡張します。横軸はサンプル順です。
- 右上の「表示・地図設定」で速度（km/h）・加速度（m/s²）・リーン角の絶対値（°）それぞれの色分け下限・上限を変更できます。下限以下は青、上限以上は赤。0以上かつ上限>下限が必要です。設定はこのブラウザのlocalStorageへ保存し、再起動時に復元します。初期値へ戻すボタンもあります。軌跡・リーン柱の色と凡例に反映し、保存済み実測値は変更しません。

## 地図

初期状態はOpenStreetMapです。3Dは傾斜した平面地図とデータの立体表現であり、実地形の標高メッシュではありません。

Google Mapsを使用するには、Google CloudでMaps JavaScript APIと課金を有効にしたAPIキーを用意し、右上の地図設定で入力してください。キーはこのブラウザのlocalStorageに保存し、GitHubへ送信しません。HTTPリファラー制限を `https://kerohiro.github.io/*` に、API制限をMaps JavaScript APIに設定してください。Google Mapsの料金・利用制限は利用者側の設定に依存します。傾斜は地図の地域・ズーム・対応状況に依存し、標準地図のリーン柱はGoogle側では表示しません。

Apple Mapの地図埋込は未実装です（MapKit JSの認証設定が別途必要）。選択位置をApple Mapで開けます。

## 精度と制限

- リーン角は `accelerationIncludingGravity - acceleration` の反対方向から重力方向を推定し、キャリブレーションした車体軸へ射影して求めます。ブラウザ・OSごとの符号やセンサー融合の差、旋回中の持続加速度、振動の影響があります。実走精度は未検証です。安全判断や計測器としての利用を想定しません。
- 加速度は車体座標（右・前・上が正）、m/s²。角速度の生値はブラウザ仕様のdeg/s（Swift版はrad/s）。ブラウザが線形加速度を返さない場合は欠測として表示します。
- GPS速度・方位が無効なら欠測扱いです。地図上の加速度矢印は車体水平成分をGPS進行方向で投影した参考値で、リーン・ピッチまで補正した対地ベクトルではありません。
- GPSは水平精度50m以内、3秒以内の最新値をIMUに紐付けます。10Hzの独立測位ではありません。
- 軌跡は最大約1200セグメント（Google側約800）に間引いて表示します。保存データは間引きません。記録・JSON読込は50万サンプルまで。長時間の実機負荷は未検証です。
- DEMOは合成データです。実際の道路に沿った実走ログではありません。
- データはブラウザ内にのみ保存。GitHubに走行データやキーをアップロードしません。地図・フォントの取得時は各提供元と通信します。ブラウザ間・端末間の同期や、バックグラウンド記録はありません。

## 開発

Node.js 22以降:

```sh
npm ci
npm test
npm run dev
npm run build
```

`dist/` を静的ホスティングできます。相対パスのためGitHub PagesのプロジェクトURLに対応しています。センサー実測はHTTPSまたはlocalhostが必要で、MacのLAN内HTTP URLをiPhoneで開くだけでは動作しません。

## GitHub Pages

Settings → Pages → Source: **GitHub Actions**。
`main` へのpushで `.github/workflows/pages.yml` がテスト・ビルドし、`dist/` のみを公開します。ソースコードにGoogleキーや実走行データを含めないでください。
